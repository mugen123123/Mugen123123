# Inbox

Drop new homework here: PDFs, Word docs, PowerPoints, spreadsheets, screenshots, photos of worksheets, rubrics, class notes. Put everything for one assignment in at once if you can.

Then just tell Claude something like "do the new homework in the inbox" (add the due date or any teacher instructions that aren't in the files).

Claude will move the files into that assignment's `Original_Materials/` folder, unchanged, and work from there.
